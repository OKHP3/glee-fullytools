# Content, product, information architecture, and discovery assessment

Review date: 2026-09-05. Worker: content/product, under the Assessment Project Manager. Baseline: local main `5da80578` as supplied and confirmed by the architect team. Scope: all 63 production HTML files, all 42 Tool-ette pages, seven branches, supporting journeys, search index and its producer/consumer, sitemap, feed, canonical suite contract, and relevant historical/editorial records. Production sources and Git refs were not changed. Only this report and two machine evidence files were written.

## Assessment

The site has a strong authored identity and unusually explicit internal governance, but its public product promises are less coherent than its structural checks suggest. The largest opportunity is to make discovery reliable: a visitor should understand what a helper does, whether it can be tried, what will happen after leaving the site, and what evidence supports the description. Today's catalog has the structural bones to do this without a framework rewrite, a new CMS, a taxonomy rename, or deleting prototype pages.

The broad inventory is confirmed: 63 production HTML files, 60 search entries, seven branch hubs, 42 Tool-ettes, and 49 feed entries. Titles and descriptions are unique across the 63 files. The primary CTA classifier reproduces 1 live, 24 beta, and 17 unavailable Tool-ettes. These counts describe local publication state only. Fresh destination identity, ownership, account access, and behavior were not tested by this worker.

The claim that all 42 leaf pages are authored and meaningful is contradicted by one published template: Scheduling Wizard. The destination-withholding work also stops at primary launch buttons; secondary direct links still expose several unavailable entries. Neither problem is caught by the existing promise audit.

## Current product strengths to preserve

1. The homepage now openly explains 1 live, 24 beta and 17 unavailable entries (`index.html:217`). The suite contract explicitly distinguishes catalog readiness from external GPT quality. This is a credible base for trustworthy discovery.
2. Stable numbered routes, seven domain hubs, leaf descriptions, breadcrumbs and Keep exploring trays give the catalog a coherent shape. Most leaf pages have rich authored inputs, outputs, functions and handoffs. The repair should strengthen the existing taxonomy rather than flatten it.
3. The warm personal story and About/Persona/Showcase split provide an unusually recognizable identity. Portfolio proof should become more precise, not more corporate.
4. Every production page has a unique title and description. All 60 intended public index routes are represented. The missing work is semantic accuracy and freshness, not wholesale metadata generation.
5. Search has a dedicated page, a URL query on load and a no-JavaScript directory; there is useful progressive enhancement to retain. Shared code and a lightweight static index are sufficient at this catalog size.
6. Health pages already include important professional-care limitations, and Legal explicitly distinguishes third-party platform privacy from the site. Move relevant boundaries into the launch journey without converting the site into medical guidance.

## Current primary-source guidance

Google requires required SoftwareApplication properties including a rating or review for software rich-result eligibility; syntactically valid JSON-LD alone does not meet that test. None of the 42 inspected graphs carries either. This supports correcting the eligibility assertion, not fabricating review content. [Google SoftwareApplication documentation](https://developers.google.com/search/docs/appearance/structured-data/software-app), retrieved 2026-09-05.

Google says sitemap lastmod should reflect the last significant page update. This supports recovering real content-change dates and avoids confusing deployment/build time with editorial change time. [Google sitemap documentation](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap), retrieved 2026-09-05.

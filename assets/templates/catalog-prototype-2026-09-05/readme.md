# Glee-fully catalog design proposal: not adopted

This is the preserved September 5, 2026 homepage, browsing, and detail design study. It is a development artifact, not a production page or approved redesign. Open `index.html` directly in a browser; the six implementation, data, and owned-image files are self-contained and preserved byte-for-byte from the original local prototype. No server, installation, or network dependency is required for the study. Links labeled current catalog page open the existing public website.

The original remains in the session visualization directory under `remaining-program/catalog-prototype/`. This archive was created against repository baseline `547d1c122b774f1aef55b92ee28739aa5d5def9a`. `catalog-data.js` preserves its original snapshot provenance: reviewed working-tree content based on `f5f33986e6ee287fb165c75e82ef01e5d3ed1f99`, generated on September 5, 2026. Its source index SHA-256 is `4166767535f779991a489744a46517863e01af25d27750ed8fdd3732d5d72c62`, matching the index at archival time. Do not reinterpret the original baseline field as an exact clean source commit.

The snapshot contains seven branches and 42 Tool-ettes: one live, 24 beta, and 17 unavailable. Descriptions and publication states come from the reviewed generated catalog. Scheduling Wizard demonstrates source-grounded inputs and intended output; this proposal does not certify external GPT behavior or add exports or integrations.

Try these review journeys:

1. Filter Unavailable, search Scheduling, and open its details. Review the inputs, intended output, and unavailable state.
2. Close with Escape, reopen, and choose Explore this branch. Keyboard focus moves to the catalog heading.
3. Reset filters, choose Organized Life, then compare its six entries. Reset again to see all 42.
4. Open the status guide using a keyboard and switch light/dark mode.

The Glee-fully brand profile version 1.1.0 supplied the paper, ink, pink, teal, and typography roles. The two existing owned butterfly images are included for portability under the explicit archival authorization. Font families use system fallbacks when the named fonts are unavailable; no fonts were downloaded. This is not human assistive-technology, branded-font, or user-research acceptance.

`assets/templates/` is excluded from production HTML validation, search indexing, sitemap content, and the allowlisted Pages artifact. Keep this archive development-only. Screenshots, measurements, and QA helpers were intentionally not copied into it. Adoption requires a separate design and implementation decision; preserving the study does not adopt it.

---
name: Search-console evidence boundary
description: Keep owner-controlled Google and Bing verification evidence separate from unrelated coding work.
---

Do not block unrelated coding tasks on Google Search Console or Bing Webmaster Tools verification, sitemap submission, indexing results, or aggregate success evidence. Keep any unsupported console status explicitly `UNKNOWN` or `BLOCKED`; do not infer verification or submission from Google Analytics code or from a missing property in only one signed-in account.

**Why:** the owner instructed that real console setup and result capture remain deferred, and that missing success evidence must not hold up unrelated coding work.

**How to apply:** Update the discovery evidence only with dated, sanitized observations and clear provenance. Do not create accounts, submit sitemaps, alter DNS or permissions, claim indexing success, or require console results for unrelated code changes.
